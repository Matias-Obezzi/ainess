# Informe de Implementación UI

## Qué se hizo
Se implementó por completo la interfaz gráfica de usuario descrita en el plan. Se reemplazó `src/App.tsx` para definir el layout principal que incluye el `Header` superior y un sistema de pestañas. Se construyeron e integraron los componentes para cada pestaña: `PromptPanel` para enviar instrucciones, `CommunicationPanel` para ver los mensajes con filtros y autoscroll, `HierarchyGraph` implementando el grafo de jerarquía con React Flow y un componente nodo personalizado (`AgentNode`), y por último `AgentsPanel` y `AgentDialog` para administrar la configuración de cada agente. Se implementaron los hooks `useActivityIsland` y `useNotifications` para manejar las alertas globales.

## Decisiones tomadas
- React Flow requiere algo de CSS adicional para mostrarse correctamente en modo oscuro. Se agregaron overrides específicos en `src/index.css` que ajustan el color de fondo, los controles y el minimap utilizando las variables CSS globales del tema (`--background`, `--card`, `--border`, etc.).
- En `AgentsPanel`, se usó `await island.confirm()` en lugar del callback `onConfirm` para el borrado de agentes, debido a que la API de `ConfirmOptions` en la librería arroja un error de tipado al pasar funciones de callback directamente, operando más bien mediante promesas.

## Pendientes o dudas
- La interfaz no implementa scroll-to-bottom condicional en `CommunicationPanel` (es decir, deja de hacer scroll si el usuario sube a leer un mensaje anterior) tal como sugería el plan ("auto-scroll ... si el usuario no scrolleó hacia arriba"). Actualmente hace un simple `scrollIntoView()` cada vez que llega un mensaje. Para lograr lo otro se requiere lógica más compleja de eventos de scroll.
- Se removieron un par de variables sin uso en `PromptPanel` (ej: `selectRoots` extraído pero no usado) para satisfacer las reglas estrictas de TypeScript (`noUnusedLocals`).
