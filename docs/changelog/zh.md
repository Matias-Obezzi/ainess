# 更新日志

0.6.0 之前的版本记录在仓库的 CHANGELOG 里，为英文。

## 0.6.0 — 2026-09-08

### 新增

- **文件随消息一起发送。** 输入框里的回形针，或者直接用 Ctrl+V 粘贴：截图、PDF、日志都行。图片在发送前
  会显示缩略图，其他文件显示名称和大小，随时可以移除。发送时，文件会被复制到项目自己的
  `.ainess/attachments/` 目录，提示词里带上它的路径 —— 这是所有 CLI 都能处理附件的唯一方式，因为它们
  都会读取自己所在的仓库。

### 修复

- 有智能体在工作的项目，用它自己的圆点缓慢呼吸来表示。以前名字旁边挂着一个橙色计数，看起来像有事在等
  你回应 —— 现在只有侧栏底部那个真正需要你的琥珀色标记才是那个样子。
- 从右键菜单删除时，询问出现在窗口顶部的胶囊里，那是为手机准备的形式，而不是对话框。这只在开发这个应用
  时发生，而且还可能把问题整个弄丢。
- 钩子的 `{{` 列表现在会说明每个变量存的是什么，而不只是名字，方向键也会让列表滚动：以前过了第八个，
  高亮项就跑到看不见的地方。
