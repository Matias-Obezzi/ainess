# 変更履歴

0.6.0 より前のバージョンは、リポジトリの CHANGELOG に英語で残っています。

## 0.6.0 — 2026-09-08

### 追加

- **ファイルがメッセージと一緒に届きます。** 入力欄のクリップ、または Ctrl+V で直接貼り付け。スクリーン
  ショット、PDF、ログ。画像は送る前にサムネイルを、それ以外は名前とサイズを表示し、どちらも取り消せます。
  送信時にファイルはプロジェクト自身の `.ainess/attachments/` にコピーされ、プロンプトはそのパスを運びます
  —— どの CLI も自分が作業しているリポジトリを読むので、これが添付に対してすべてができる唯一のことです。

### 修正

- エージェントが動いているプロジェクトは、その点自体がゆっくり呼吸して知らせます。以前は名前の横にオレンジ
  の数字が付いていて、返事を待っている何かのように見えました —— サイドバー下部の、本当にあなたを必要とする
  琥珀色のバッジだけが、いまはその見た目です。
- 右クリックメニューからの削除が、ダイアログではなくウィンドウ上部のピル、つまり電話向けの形で尋ねていま
  した。アプリの開発中にだけ起き、しかも質問そのものを失うこともありました。
- フックの `{{` の一覧が、名前だけでなく各変数の中身を説明するようになり、矢印キーで一覧がスクロールします。
  以前は八つ目を過ぎると、選択中の項目が見えない位置へ移動していました。
