# 変更履歴

0.6.0 より前のバージョンは、リポジトリの CHANGELOG に英語で残っています。

## 0.7.0 — 2026-09-08

### 追加

- **スキルは当てはまるときに開かれ、毎回の実行に丸ごと注ぎ込まれることはなくなりました。** これまでスキ
  ルは、それを有効にしたエージェント全員のシステムプロンプトの中を丸ごと運ばれていました。五つのスキル
  は、読まれようが読まれまいが、毎回の実行で五冊のマニュアルでした。いまはそれぞれが
  `.ainess/skills/<名前>/SKILL.md` に書き出され、プロンプトが運ぶのは名前と、何のためのものかの一行と、
  そのパスだけです —— エージェントは目の前の仕事に関わるものだけを開き、スキルが必要とするもの（スクリ
  プト、テンプレート）も同じフォルダに置けます。判断の材料はその説明の一行なので、エディタもそう言うよ
  うになりました。
- **通知に音がつきました。** 短い二音。あなたを必要とするときは上がり、何かが終わったときは下がるので、
  見なくても区別できます。音はアプリが合成します —— インストーラーに音声ファイルはありません —— そして
  ウィンドウでも、トレイから（アプリはそこで生き続けており、それこそが音を届かせている理由です）も、電
  話でも同じように鳴ります。設定 → 一般で切ることができ、そのエディタで音符・波形・音量を調整するか、
  自分の音に差し替えられます。
- **各エージェントの履歴が、プロジェクトの中に。** `.ainess/history/` にエージェントごとに一つのファイ
  ルができ、ターンが終わるたびに追記されます。誰が頼み、何を頼み、何が返ってきたか。委譲された仕事も、
  会話も同じです。アプリはすべてを自分のストレージに持っていて、そこはアプリしか読めません。明日戻って
  くるエージェントにとっても、エディタを開いたあなたにとっても、この入口がすべてです。ファイルがいっぱ
  いになるとターン単位でまるごと捨てられ、途中で切られることはありません。
- **ターミナルのタブは好きな順にドラッグできます**。タブのあるエディタと同じで、運んでいるタブは薄くな
  り、どこに落ちるかを線が示します。
- **マシン自身の状態に反応するフック。** これまでフックはエージェントがしたことに答えるものでした。さら
  に五つのイベントがマシンに答えます。アプリの起動、時計（一日のある時刻、または何分おき）、接続が切れ
  たときと戻ったとき、そしてプロジェクトのフォルダでファイルが変わったとき —— 最後のものは元からあった
  ウォッチャーに乗っているので、ノイズ（`.git`、`node_modules`、ビルド出力）は届きません。アプリが開い
  ている間だけ動き、それぞれ一分に一度までで、対象のプロジェクトはフックのフィルタのもの、なければ開い
  ているものです。すでに発火していた `approval.requested` も、ようやく選べる一覧に入りました。
- **変更履歴があなたの言語で。** 更新後に開くダイアログと、設定 → について、が翻訳された内容を表示しま
  す。英語は `CHANGELOG.md` に残り、ほかの言語はそれぞれ自分のファイルを持ち、リリースチェックが公開さ
  れるバージョンと歩調を合わせ続けます。
- **五分ごとに新しいバージョンを探します**。起動時の一度だけではないので、アプリを開いている間に公開さ
  れたリリースがその日のうちに届きます。案内はこれまでどおり、設定の同じスイッチで切れます。
- **ターンを打ち切って何か言う。** エージェントを待っているメッセージに二つ目のボタンがつきました。走っ
  ているものを止めて、その場でメッセージを渡します。何も繰り返されません —— エージェントがしたことはディ
  スクにあり、言ったことは自分のセッションにあって、次の実行がそれを引き継ぎます —— そしてターンが打ち
  切られたことも伝わるので、記録を「終えたターン」として読むことはありません。
- **入力欄のコマンド。** 空の入力欄で `/` を打つと短い一覧が開きます。`/compact` はプロジェクトのすべて
  のエージェントに新しいセッションを始めさせます —— 何も失われません。それぞれが `.ainess/history/` の
  自分のファイルを指し示され、新しい仕事に必要な分だけを読み直すからです —— そして `/cost` はこのプロ
  ジェクトが使った分を開きます。入力欄のそれ以外はすべてメッセージなので、「Claude の /compact を見て」
  はそのままチームに届きます。

### 修正

- **指示が毎ターン送り直されていました。** エージェントの前置き —— 役割、`delegate` と `ask` の書式、共
  有コンテキスト、プロフィール、スキルの一覧 —— が、CLI がすでに引き継いでいる会話の一通ごとに一緒に送
  られていました。Claude では同じ段落がターンのたびに課金され、指示をプロンプトの中に入れるプロバイダ
  （Antigravity、Copilot、opencode ほか）では、記録の中にもう一部の写しが永久に残り、長いセッションはそ
  の分を何度も払っていました。いまは一度だけ、セッションを開くターンに送られます。毎ターン送られ続ける
  のはボードで、そこが変わる部分だからです。
- プロジェクトはファイルマネージャーで自分のフォルダを開けます。右クリックからも三点メニューからも同じ
  で、この二つのメニューは同じものである限りどこでも同じ動作を並べるようになりました。プロジェクトのパ
  スは右クリックにだけあって三点にはなく、会話の「開く」は逆でした。
- 一つのプロジェクトのルートに二人のオーケストレーターを置けなくなりました。チームのダイアログが二人目
  に親を求めます。もともとそこが居場所でした。横に並んでいると二人ともボード全体を読み、同じカードを取
  りうるのに、入力欄・CLI・電話が既定で書き込む先は最初の一人だけで、プロジェクトに一つしかない「作業中
  のタスク」のポインタは一方がもう一方を上書きしてしまい —— 最初のタスクはカードが動かず、フックも走ら
  ず、通知も出ませんでした。すでに二人いるチームは、どちらを開いてもすぐそう言います。
- エージェントの CLI を変えても古いほうのセッションが残っていて、次の実行は Claude が開いたセッション
  ID を Antigravity に渡していました —— もう一方が聞いたこともない名前なので、その場で失敗します。いま
  は CLI が変わったときにセッションを捨てます。エージェントが自分の worktree に入る／出るときも同じで、
  そちらもセッションが結びついているもう半分です。
- リポジトリのウォッチャーは、アプリ自身の `.ainess/` フォルダでは目を覚まさなくなりました。ボードもチ
  ームも、そしていまは履歴も、作業中にそこへ書き込まれるので、ファイルのフックはユーザーではなくアプリ
  に答えてしまっていました。
- フックは対象を二度たずねていました。エージェント用の欄と、プロジェクト用の欄です。いまは一つです ——
  すべて、プロジェクト全体、またはその中の一人 —— エージェントはちょうど一つのプロジェクトに属するので、
  この組み合わせは一致するか、矛盾して永久に発火しないかのどちらかにしかなりませんでした。
- プロジェクトをまたぐエージェントの一覧 —— フックが指示する相手、フックの絞り込み先、保存した指示の紐
  づけ先 —— は、それぞれが属するプロジェクトごとに、その色とともにまとめられます。「オーケストレーター」
  が一人ずついる二つのプロジェクトは、以前は同じに見えていました。
- あなた自身が書きかけるエージェントには、それが誰なのかが伝わります。仕事がプランナーから来ようとあな
  たから来ようと同じプロンプトを読んでいたので、実装者はあなたのメッセージをさらに委譲して答え —— その
  あと「チームを待っています」で止まっていました。
- その待ち自体ももう終わりです。そのエージェントの下にいない相手を名指しした委譲は、決して来ないチーム
  を待たせ続けていました。一件も着地しなかったときは、エージェントは自由に戻ります。
- ターミナルのリンクはワンクリックで開きます。以前は CLI が自分で印をつけたものだけがリンクで、しかも
  Ctrl を押さえておく必要がありました。いまは出力の中のどの URL もリンクで、本物のブラウザで開きます。
- 電話では、キーボードが入力中の欄を覆っていました。ページはキーボードが開いてもわざとサイズを変えませ
  ん —— 以前はそれが作業の途中で会話を下端のアンカーから外していました —— ので、代わりにキーボードが占
  める分だけアプリを縮めます。
- 「新しいバージョンがあります」のトーストが、リリースノートを書かれたまま表示していて
  `[CHANGELOG.md](https://…)` と読めていました。トーストにはそれを描画する markdown がありません。いま
  は言うべきことだけを言い、何が変わったかは更新後に開く変更履歴にあります。
- エージェントが動いている間に書いたメッセージが、コミュニケーションにだけ現れ、ほかのどこにも出ません
  でした。アプリが飲み込んだように見えます。いまは会話の末尾に、破線と時計つきで、誰を待っているかを添
  えて残り、順番が来る前なら取り消せます。
- そのメッセージは早く渡されすぎることもありました。委譲するエージェントは、チームが終わる前に自分の実
  行を終えるので、キューはそこで空にされていました —— メッセージは、後に続くはずだった仕事の横を走って
  いたのです。いまはエージェントが本当に空くまで待ちます。

## 0.6.0 — 2026-09-08

### 追加

- **ファイルがメッセージと一緒に届きます。** 入力欄のクリップ、または Ctrl+V で直接貼り付け。スクリーン
  ショット、PDF、ログ。画像は送る前にサムネイルを、それ以外は名前とサイズを表示し、どちらも取り消せます。
  送信時にファイルはプロジェクト自身の `.ainess/attachments/` にコピーされ、プロンプトはそのパスを運びます
  —— どの CLI も自分が作業しているリポジトリを読むので、これが添付に対してすべてができる唯一のことです。

### 修正

- エージェントが動いているプロジェクトは、その点自体がゆっくり呼吸して知らせます。以前は名前の横にオレンジ
  の数字が付いていて、返事を待っている何かのように見えました —— サイドバー下部の、本当にあなたを必要とする
  琥珀色のバッジだけが、いまはその見た目です。
- 右クリックメニューからの削除が、ダイアログではなくウィンドウ上部のピル、つまり電話向けの形で尋ねていま
  した。アプリの開発中にだけ起き、しかも質問そのものを失うこともありました。
- フックの `{{` の一覧が、名前だけでなく各変数の中身を説明するようになり、矢印キーで一覧がスクロールします。
  以前は八つ目を過ぎると、選択中の項目が見えない位置へ移動していました。
